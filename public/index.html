Túnel VPN Web

Al hacer clic en cualquier resultado, el servidor actúa como un proxy cifrado intermedio. Tu IP real nunca llega al sitio destino y tu proveedor de internet (ISP) no ve la web que visitas.

ACTIVO

DNS Seguro del Sitio (DoH)

Servidor DNS-over-HTTPS (RFC 8484) integrado. Previene envenenamiento de DNS, censura y espionaje de resoluciones de dominio.

Configura tu navegador o móvil con el DNS de este sitio:

Protege todo tu dispositivo contra bloqueos y espionaje configurando el DNS Seguro en Chrome, Firefox, Edge o Android:

  1. En Chrome / Edge / Brave: Ajustes → Privacidad y seguridad → Usar DNS seguro → Con: "Personalizado" → Pega la URL de arriba.
  2. En Firefox: Ajustes → Privacidad → DNS sobre HTTPS → Protección Máxima → Personalizado.
  3. En Android: Ajustes de red → DNS privado.
